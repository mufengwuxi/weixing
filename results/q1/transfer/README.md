# 第一问求解器的可迁移性检验

`code/p1/solver.py` 中的候选观测时刻、相位差和初始脉冲估计都由数据现算（论文 5.2 节），不含针对 B1 的常数。
不改代码，只换 `--target`，用同样的设置（裕量 0.01 km / 0.01°，60 s，60 个初值，种子 2）求解：

| 目标 | 最小累计 Δv（m/s） | 说明 |
|---|---|---|
| B1 | 5.2128 | 主方案，80 个初值的第 1 个即找到 |
| B7 | 8.9752 | 第一次脉冲在 t = 0，第二次几乎为零 |
| B20 | 34.8324 | 第二次脉冲达到 30 m/s 上限 |

命令：`python code/p1/solver.py --out results/q1/transfer/q1_b7.json --margin-d 0.01 --margin-a 0.01 --starts 60 --seed 2 --target b7`
