# 第一问：两个可能观测时段的对比

用 `code/p1/solver.py` 的瞄准 + 精修流程（裕量 0.01 km / 0.01°，60 s，0.05 s 网格认证），把观测中点强制放在第一个时段（R1 穿越 B1 轨道面约 14.45 h 处），随机种子 3，80 个初值。

| 观测时段 | 最小累计 Δv（m/s） | 观测开始 |
|---|---|---|
| 第一个时段（约 10.2–22.2 h） | 13.3549 | 约 14.50 h |
| 第二个时段（约 34.2–46.2 h），主方案 v4 | 5.2128 | 38.43 h |

第一个时段的 80 个初值中有 5 个收敛到同一最优值 13.354883 m/s，结果稳定。第一个时段的代价约为第二个的 2.6 倍，原因是第二个时段留给相位调整的时间更长（论文 5.3 节）。
