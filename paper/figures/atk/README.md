## 复现步骤

1. `python tools/make_view_scene.py <方案> <卫星名> <输出> --step <s> --upper [--scenario-name Scenario1]` 生成场景（第一问 `--step 1`，其余 `--step 60`）；本目录图片对应的场景文件已生成（见上表路径），卫星名大写。
2. ATK 打开场景文件，关闭左侧对象树与右侧属性面板（点面板标题栏 ×），使 3D 视图 ≥1920×1080。
3. 底部时间栏点击输入场景时间（格式 `2 Jan 2027 14:26:16.000`）回车。
4. 3D 视图内右键 → 相机控制，按上表输入经度/纬度/高度（每项回车确认）。
5. 截取屏幕 3D 区域（本机为 (0,92)–(2560,1292)）。

## 备注

- 相机经纬为 ATK 相机控制对话框的地心经纬度口径（closeup 的 118.1° 由 B1 在观测时刻的星下点地固经度算得，GMST≈318.57°）。
- 场景由 `make_view_scene.py --upper` 生成：R1/R2 红色、B* 浅蓝、Q2/Q3 目标轨道线关闭，均已写入场景文件本身，重开即为同样式。
