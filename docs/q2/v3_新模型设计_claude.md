# 第二问新模型（v3 设计稿）：全计划序列凸优化 + 自适应大邻域搜索

## 1. 现有方法的问题

现在第二问的求解（`code/p2`、`code/p3/v3`）分两层。上层用漂移相位模型做束搜索，排出一个访问顺序。下层按这个顺序逐段做 SLSQP，每段只让自己这一段的 Δv 最小。缺的目标再一颗一颗地插进去。

这个流程有三处缺陷。第一，逐段最优是短视的。每段只看自己的代价，不管末状态会给后面几段造成多大负担。新数据上插入 b25 之后，后面每一段都变贵，原因就在这里。第二，上层的代价模型太粗。束搜索按"漂移率变化 × 2.85 m/s/(°/天)"估计每段代价，没有考虑观测几何对相对状态的约束，所以排出来的顺序常常在精确求解时失败，或者代价高出很多。第三，插入只是修补。缺哪颗就往哪里塞，没有一个对整个计划做全局评估的标准。

## 2. 新模型

### 2.1 决策变量分成两层

**组合层**：访问序列 $\pi = (b_{\pi_1}, \dots, b_{\pi_m})$，以及每次观测选在哪一天的机会 $\kappa_k$（每颗目标大约每天一次）。

**连续层**：给定 $(\pi, \kappa)$ 之后，所有脉冲 $\{(t_k, \Delta\boldsymbol v_k)\}$ 和每次观测的精确开始时刻 $s_k$。

### 2.2 连续层：整个 30 天计划一起做凸优化

这是新模型的核心改动。我们不再逐段求解，而是对整条计划做一次联合优化。

**线性化动力学。** 在当前名义轨迹 $\bar{\boldsymbol x}(t)$（精确二体传播）附近，第 $k$ 次脉冲对之后任意时刻状态的影响是线性的，由开普勒状态转移矩阵 $\Phi(t, t_k)$ 给出：

$$\boldsymbol r(t) \approx \bar{\boldsymbol r}(t) + \sum_{t_k < t} \Phi_{rv}(t, t_k)\,\delta\Delta\boldsymbol v_k .$$

**观测约束写成凸集。** 记 $\boldsymbol\rho = \boldsymbol r_O - \boldsymbol r_b$，太阳方向单位矢量为 $\hat{\boldsymbol s}$，地心方向单位矢量为 $\hat{\boldsymbol e}$。光照角 $\alpha \le 45^\circ$ 和侦测角 $\theta \le 45^\circ$ 分别对应两个顶角为 90° 的圆锥，

$$\|\boldsymbol\rho\|\cos 45^\circ \le \hat{\boldsymbol s}^{\top}\boldsymbol\rho,\qquad \|\boldsymbol\rho\|\cos 45^\circ \le \hat{\boldsymbol e}^{\top}\boldsymbol\rho ,$$

两者都是二阶锥约束。距离上限 $\|\boldsymbol\rho\| \le 50$ 也是二阶锥约束。距离下限 $\|\boldsymbol\rho\| \ge 10$ 不是凸约束，我们用半空间 $\hat{\boldsymbol g}^{\top}\boldsymbol\rho \ge 10$ 作内近似，其中 $\hat{\boldsymbol g}$ 取两个锥轴的角平分方向。满足这个半空间就一定满足 $\|\boldsymbol\rho\| \ge 10$。这四个集合的交集是凸集。观测区间只有 60 s，远短于轨道周期，相对运动在这段时间内近似直线，所以只要观测起点和终点两个时刻都落在凸集内，整段观测就都在凸集内。

**单次凸子问题。** 给定 $(\pi, \kappa)$、各脉冲时刻和观测时刻，最小化全计划总 Δv 是一个二阶锥规划（SOCP）：

$$\min \sum_k \|\Delta\boldsymbol v_k\| \quad \text{s.t.}\quad \|\Delta\boldsymbol v_k\| \le 30,\quad \boldsymbol\rho_j(s_k),\ \boldsymbol\rho_j(s_k+\tau) \in \mathcal C_j(s_k),\quad \text{信赖域}\ \|\delta\Delta\boldsymbol v_k\| \le \Delta .$$

它的变量约 $6m$ 个（$m \le 30$ 段，每段两次脉冲），求解只需几毫秒。在线性化成立的范围内，它给出的是这组序列和时刻下的全局最优。

**序列凸化（SCP）。** 用 SOCP 的解更新脉冲，再用精确二体模型重新传播名义轨迹，然后重新线性化，反复几轮直到收敛。收敛后的解满足精确的二体动力学，最后再用 0.05 s 网格和 ATK 做认证。脉冲时刻用一维搜索加 SOCP 的灵敏度信息去调。

### 2.3 组合层：自适应大邻域搜索（ALNS）

组合层的目标按字典序比较 $(|S|,\ -J)$。以连续层的 SCP 为评价器，在 $(\pi, \kappa)$ 上做 ALNS。破坏算子有三种：随机移除一段连续的访问；移除代价最高的几次访问；移除经度相邻的一组目标。修复算子有三种：贪心插入；后悔值插入（regret-2）；把某次观测改到相邻的一天。在每轮修复里，插入位置的初筛用一个廉价代理代价，也就是经度–时间平面上的漂移率变化，排名靠前的候选才交给 SCP 精确评价。接受准则用模拟退火。

**字典序和预算的处理。** 由于每颗星的累计 Δv 不超过 300 m/s，如果给每颗目标设一个大于 300 m/s 的奖励 $P$，那么最大化 $P|S| - J$ 与字典序目标严格等价：多看一颗目标的收益一定超过任何 Δv 的差别。这个"权重"是从预算上界推导出来的，不是随意取的定值，符合题面"不得用未经分析的固定权重"的要求。

### 2.4 下界

把"每颗目标至多访问一次"的约束拉格朗日松弛掉之后，组合层就变成时间–经度图上的最短路问题，可以在有向无环图上用动态规划求解。这样可以得到总 Δv 的一个下界，论文里可以用它报告当前方案与最优之间的差距。

## 3. 和旧方法的比较

| | 旧方法 | 新模型 |
|---|---|---|
| 连续优化的范围 | 逐段，短视 | 全计划联合 SOCP，再用 SCP 收敛到精确二体解 |
| 观测约束的处理 | 每段 SLSQP 的非线性约束 | 二阶锥凸集（锥、球、半空间） |
| 顺序搜索 | 粗代价下的束搜索，缺的目标逐颗插入 | 以全计划代价为评价器的 ALNS |
| 字典序 | 先排后插 | 奖励 $P > 300$ 与字典序严格等价 |
| 最优性证据 | 只有局部改进实验 | 拉格朗日下界给出差距 |

第三问可以直接复用：两颗星的计划在同一个 ALNS 里搜索，破坏和修复算子同时作用在两条序列上，目标的分配也一起优化，不必预先按经度分组。

## 4. 实施步骤

1. 实现全计划 SOCP 和 SCP 评价器（cvxpy 或 clarabel），在现有的 30 颗方案上热启动，检验联合优化能把总 Δv 降多少。
2. 实现 ALNS 外层，在新数据上从头求解第二问。
3. 用拉格朗日松弛求下界。
4. 把同一框架用于第三问（两条序列 + 自动分配）。
