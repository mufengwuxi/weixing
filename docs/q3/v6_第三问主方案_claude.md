# 第三问 v6（Claude）：主方案，δa 取目标同步带宽度 5.90 km

## 结果

模型与 v5（M3-C）相同，δa 取 5.90 km。两颗星合计观测 30 颗目标，总 Δv 为 **33.460 m/s**，其中 r1 为 18.148 m/s（与 v4、v5 相同），r2 为 15.312 m/s。按题面约束严格认证，r1 10/10、r2 20/20 全部通过。

r2 在 t₀ 时刻的初始轨道为 a = 42158.280 km（a − a_GEO = −5.89 km），e = 0.00045，i = 4.3797°，Ω = 76.964°。半长轴落在约束下界上，说明 δa 约束是起作用的约束。从两个不同的初值出发（δa = 5 km 和 δa = 8 km 的解），SCP 都收敛到同一结果（15.312 m/s），可见结果稳定。方案文件为 `solutions/q3/v6_p3_claude.json`、`v6_p3_r1.json`、`v6_p3_r2.json`，原始结果在 `code/p3/v5/final/r2_da5.90*.json`。

## δa 的取值依据

按新数据计算，30 颗蓝方目标的半长轴相对 a_GEO 的偏离都在 −5.90 km（b30）到 +4.73 km（b21）之间，其余 28 颗集中在 +0.06 ~ +3.73 km，r1 为 +1.77 km。同步带上的高轨卫星，包括题中给出的蓝方目标、其他蓝方高轨卫星，以及红方自己的高轨卫星，半长轴的偏离量都很小。R2 作为红方提前发射的高轨卫星，入轨半长轴应当和它们处在同一条同步带内。因此取 δa 等于 30 颗目标中最大的半长轴偏离量，即 δa = 5.90 km。

## 论文中的声明（草稿，待确认）

> 题目要求 δa 不得擅自取定值，本文依据目标星座的实际分布确定 δa。由附件数据，30 颗蓝方目标的半长轴相对地球同步轨道半长轴的偏离量介于 −5.90 km 与 +4.73 km 之间，红方 R1 的偏离量为 +1.77 km。同步带上蓝方其他高轨卫星和红方高轨卫星的半长轴偏离量同样较小，R2 作为红方提前入轨的高轨卫星，其初始轨道应与上述卫星同处同步带内。本文因此取 δa = 5.90 km，即目标半长轴的最大偏离量，并将该约束施加于 R2 在 t₀ 时刻的入轨轨道，t₀ 之后的机动轨道只受机动约束与速度增量预算限制。
>
> 为检验 δa 取值对结果的影响，本文在 δa = 3 ~ 19 km 范围内求解了最优总速度增量 J*(δa)，结果见表 X。J*(δa) 随 δa 单调不增，δa = 5.90 km 时总速度增量为 33.46 m/s；δa 增至约 19 km 后不再下降，此时为 33.27 m/s。两者相差 0.19 m/s，不足 0.6%，说明本文的结论对 δa 的取值不敏感。
