## 三、数学模型

### 3.1 模型假设

1. 二体运动；不考虑 J2、日月三体、光压、大气阻力；
2. r1 最多两次瞬时脉冲；b1 全程不机动；
3. 太阳仅参与光照几何，不产生加速度；
4. 机动瞬间完成（位置连续、速度跳变），60 秒观测区间内不机动。

### 3.2 动力学与轨迹参数化

无机动段满足 ṙ = v, v̇ = −μr/‖r‖³，记状态流映射为 𝒦_τ。两脉冲轨迹：

X₁⁻ = 𝒦_{t₁}(X_{O,0})，X₁⁺ = X₁⁻ + (0, Δv₁)ᵀ
X₂⁻ = 𝒦_{t₂−t₁}(X₁⁺)，X₂⁺ = X₂⁻ + (0, Δv₂)ᵀ
X_O(t) = 𝒦_{t−t₂}(X₂⁺)（t ≥ t₂）；X_T(t) = 𝒦_t(X_{T,0})

这是**精确非线性二体模型**，不是 HCW 线性相对运动近似。

### 3.3 时变可观测区域

ρ(t) = r_O − r_T，d = ‖ρ‖；ŝ(t)（目标→太阳）、ê(t)（目标→地心）单位向量，c = cos45°。由反余弦单调性，角度约束等价于余弦形式：

ŝ(t)ᵀρ ≥ c‖ρ‖，ê(t)ᵀρ ≥ c‖ρ‖

时刻 t 的可观测区域为两个半顶角 45° 的时变圆锥与 10–50 km 球壳之交：

𝒪(t) = { ρ : 10 ≤ ‖ρ‖ ≤ 50，ŝᵀρ ≥ c‖ρ‖，êᵀρ ≥ c‖ρ‖ }

其中圆锥约束与距离上界为凸约束，距离下界使 𝒪(t) 非凸。

### 3.4 连续 60 秒约束与完整优化模型

定义裕量 g₁ = d−10，g₂ = 50−d，g₃ = ŝᵀρ̂−c，g₄ = êᵀρ̂−c，连续观测约束为 min_{t∈[s,s+60]} g_j(t) ≥ 0（j=1..4）——**连续时间状态约束**。利用约束函数变化率上界，可将其严格有限化为检查点条件（步长 Δ 满足 L_g·Δ/2 ≤ ε 时，检查点裕量 ≥ ε 保证区间全程成立）。

第一问完整模型（P1）：

min_{z} ‖Δv₁‖ + ‖Δv₂‖
s.t. z = (t₁, t₂, s, Δv₁, Δv₂) ∈ R⁹；
0 ≤ t₁, t₂−t₁ ≥ 3600, t₂ ≤ s, s+60 ≤ 172800；
‖Δv_k‖ ≤ 0.03 km/s；
ρ(t) ∈ 𝒪(t), ∀t∈[s, s+60]；
动力学满足上述流映射（隐式等式约束）。

允许 m∈{0,1,2} 次机动作为并列特例参与比较。

## 四、求解框架（分层）

1. **观测窗口预筛选**：由 α、θ 同时 ≤45° 的必要条件 γ(t) = ∠(ŝ,ê) ≤ 90°，将 48 h 观测时刻域剪枝为两个窗口（A：01-01 10:09–22:09；B：01-02 10:09–22:10 UTC）。
2. **全局候选搜索**：多起点（84 个独立起点，含结构化起点与随机起点）非线性序列二次规划（SLSQP），时间变量外层、脉冲矢量内层。
3. **轨迹精修**：固定时间下基于状态转移矩阵 Φ(t,t₀)（6×6 变分方程）的一阶灵敏度模型加速收敛，最终回到完整非线性模型校验。
4. **可行性认证**：最终方案以 0.05 s 网格检查全程裕量 > 0，并以 DOP853 独立积分复算。
5. **下界分析**：轨道能量/角动量/偏心率包络 + 双圆锥几何 + 相位可达性 → 条件解析下界；时间维 Lipschitz 修正的检查点松弛管线（进行中）。

**模型对齐说明**：太阳星历采用解析模型并经 astropy/ERFA 官方星历校验（48 h 内方向偏差 ≤ 0.003°）；开普勒解析传播与 DOP853 数值积分 48 h 位置差 1.4×10⁻⁷ km。

### 5.4 物理解释（节能机理）

方案不是传统交会（速度完全匹配），而是利用**自然相位漂移**：第一次小脉冲沿切向抬高半长轴（42165.9 → 42278.5 km），改变平均运动角速度 n = √(μ/a³)，Δn ≈ −(3n/2a)Δa，在数十小时自由飞行中积累显著相位调整；第二次小脉冲精修进入时机与方向，使 r1 的轨道面穿越时刻与 b1 位置重合，以约 0.2 km/s 的自然穿越相对速度在 60 s 内保持 10–50 km 与双角约束。**题目只要求 60 s 内满足距离与角度，并未要求相对速度为零**——若错误引入速度匹配目标，会人为抬高机动量。

不同机动次数对照：零次机动 48 h 内最小距离约 963.35 km（不可行）；一次机动已知可行候选约 9.14 m/s；两次机动 5.2127 m/s（当前最佳）。该对比是已知候选间的比较，不能推出单脉冲最优下界。

## 六、全局最优性状态（须谨慎表述）

正确的数学表述：

$$0 \le J^* \le 5.212700 \ \text{m/s}$$

辅助证据与研究性指标：

- **盆地收敛证据**：84 个独立起点（多种参数化与随机结构）全部收敛至 5.213±0.005 m/s 区间，无一显著更低；
- **双实现交叉验证**：两套独立代码链结果差 6×10⁻⁶ m/s；
- **条件解析下界** J_L,c ≈ 1.783278 m/s（能量/角动量/偏心率包络 + 相位可达性），对应条件间隙约 65.8%——只能作为研究指标，不是严格认证的最优性间隙；
- 严格全局最优性证明需要：对全部机动时刻与脉冲参数区域做非线性轨道传播余项的区间认证（区间分支定界），并完整包络时间盒与太阳星历误差——**尚未完成**。

论文表述建议：**"在指定二体模型与试算场景下，获得经高精度数值验证的最佳已知可行方案 5.2127 m/s；多起点全局搜索与独立交叉验证强烈支持其接近全局最优，但未宣称严格全局最优性。"**
