> 本文档给出统一的数学模型，作为各成员计算与论文写作的公共基准。仅含模型本身，不含具体求解结果。

## 二、模型假设

1. **二体引力假设**：仅考虑地球中心引力，忽略 J2、日月三体、光压等摄动（题设给定）；太阳仅参与光照几何，不产生加速度。
2. **脉冲机动假设**：点火时长远小于自由飞行弧段，机动视为速度瞬时跳变、位置连续。
3. **质点假设**：各卫星视为质点。
4. **时间均匀假设**：统一 UTC 基准，忽略相对论效应（48 h 内影响可忽略）。

## 三、数据约定

初始状态取自 `数据.xlsx` Sheet1（第 4 行 r1、第 6 行 b1），读取后须重新检验轨道根数（半长轴、偏心率、倾角等）确认数据无误。若对 r1 初始状态做符号修正等数据试验，必须在场景配置文件中记录：原始值 → 修正规则 → 实际使用值，且不得修改原始 Excel。

## 四、决策变量与目标函数（第一问）

$$z = (t_1,\ t_2,\ s,\ \Delta\mathbf{v}_1,\ \Delta\mathbf{v}_2) \in \mathbb{R}^9$$

$$\min_z\ J(z) = \|\Delta\mathbf{v}_1\| + \|\Delta\mathbf{v}_2\|$$

## 五、约束条件

**(1) 轨道动力学约束（等式，隐式满足）**

自由飞行段：

$$\dot{\mathbf{r}} = \mathbf{v},\qquad \dot{\mathbf{v}} = -\frac{\mu}{\|\mathbf{r}\|^3}\,\mathbf{r}$$

脉冲处：**r**(t_k⁺) = **r**(t_k⁻)，**v**(t_k⁺) = **v**(t_k⁻) + Δ**v**_k。轨迹由 z 经传播解 φ 唯一确定。

**(2) 机动能力约束**

‖Δ**v**_k‖ ≤ 30 m/s；t₂ − t₁ ≥ 3600 s；Σ‖Δ**v**_k‖ ≤ 0.3 km/s；机动次数允许 0/1/2。

**(3) 观测几何约束（∀t ∈ [s, s+60]，连续成立）**

- 10 km ≤ d(t) ≤ 50 km
- α(t) ≤ 45°，θ(t) ≤ 45°（有向角，不得取绝对值）
- 数值处理采用等价余弦形式：g = cos∠ − cos 45° ≥ 0（在 0°–180° 内与原角度约束严格等价，且避免反余弦运算）

**(4) 任务时间约束**

0 ≤ t₁；t₂ ≤ s；s + 60 ≤ 172800 s。

**(5) 物理合理性约束（附加检验项）**

‖**r**(t)‖ ≥ R_E = 6378.137 km 对任务全程成立；与题面约束分开记录。

## 六、连续约束的有限化

约束 (3) 为无限维（连续区间逐点成立）。设约束函数梯度范数在区间内有上界 L_g，取网格步长 Δ 满足 L_g·Δ/2 ≤ ε（ε 为设计裕量），则"全部检查点满足 g(τ_i) ≥ ε"可保证连续约束在整个区间成立。据此无限维约束严格转化为有限个光滑不等式，且可通过加密网格任意逼近原问题。

第一问完整模型：

$$P_1:\quad \min_{z\in\mathbb{R}^9} J(z)\quad \text{s.t.}\ \ (2),\ (3),\ (4),\ (5)$$

## 七、与问题二、三的递进关系

第一问模型 P₁ 是原子子模型，定义算子：

$$\mathcal{P}(\text{当前状态},\ \text{目标},\ t_0,\ \text{预算},\ \text{截止}) \rightarrow (J^*,\ \text{机动方案})$$

- **问题二 = 序列决策模型**：在 30 天时间轴上安排访问序列，机动后状态作为下一次调用 𝒫 的初始状态（状态连续继承）；第一优先级最大化观测数量，第二优先级最小化累计 Δv（字典序，不加权）。
- **问题三 = 双层优化**：外层以 r₂ 初始轨道根数 (a₂, e₂, i₂, Ω₂, 相位) 为设计变量（a₂ ∈ [a_GEO−δa, a_GEO+δa]，δa 待定），内层为双星目标分配与各自的序列调度；两星预算独立。
- 三问共用同一动力学—几何内核，逐层向上叠加组合结构。
