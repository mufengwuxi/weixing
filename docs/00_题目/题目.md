# 赛题：高轨卫星抵近观测与全局最优轨道机动

> 本文档为竞赛题面整理，供全队统一理解使用。

## 一、任务对象

- **目标卫星**：b1、b2、……、b30 共 30 颗，位于地球同步轨道带附近（近圆高轨，周期接近地球自转周期）。
- **观测卫星**：
  - r1：初始六维状态由数据文件给出；
  - r2：第三问新增，初始轨道允许自主设计。
- **坐标系/历元**：地心惯性系 ICRF，初始历元 2027-01-01 00:00:00 UTC。
- **单位约定**：位置 km，速度 km/s，时间 s；速度增量结果优先以 m/s 展示。

## 二、三问概述

### 问题一：单目标观测（当前优先级最高）

用 r1 观测 b1，要求在 **48 小时内**（截止 2027-01-03 00:00 UTC）完成至少一次有效观测，给出具体机动方案。需确定：

- 机动次数、每次机动时刻与三维速度增量；
- 机动后轨道、相邻机动间及末次机动至观测开始的自由飞行时间；
- 观测开始/结束时间；
- 全部观测约束验证；
- 最小累计速度增量。

### 问题二：单星观测 30 目标

用 r1 在 **30 天**（2,592,000 s）内尽可能多地观测不同目标。第一优先级：最大化成功观测数量；第二优先级：最小化累计机动速度增量。

### 问题三：双观测卫星协同

题面原文（开头部分）：为弥补单个卫星观测能力不足，红方提前发射一颗轨道偏心率小于 0.001 的高轨卫星 R2，与 R1 共同执行观测工作，从 t₀ 时刻开始，在 30 天内对蓝方的 30 个目标进行观测。

理解：R2 在 t₀ 之前已经入轨，t₀ 时刻的轨道就是我们设计的"初始轨道"，它必须满足偏心率小于 0.001 和下面的半长轴范围；t₀ 之后的机动照常计入 R2 的 Δv，机动后的轨道不再受偏心率限制。r1 与 r2 协同，30 天内共同完成观测。r2 约束：

- 位于同步轨道附近；偏心率 e2 < 0.001；倾角、升交点赤经、初始相位可优化；
- 半长轴范围为待定参数 δa：a_GEO − δa ≤ a2 ≤ a_GEO + δa（不可擅自取定值）；
- 两星累计机动预算相互独立。

三问共同采用**字典序优化**：先最大化成功观测的不同目标数量，再最小化全部观测卫星累计机动量之和；不得用未经分析的固定权重混合两个目标。

## 三、观测几何定义（全队必须统一）

- **观测距离**：d(t) = ‖r_O(t) − r_T(t)‖，要求 **10 km ≤ d(t) ≤ 50 km**。
- **光照角 α**：以目标星为顶点，"目标→太阳"与"目标→观测星"两矢量的夹角，要求 **α ≤ 45°**。
- **侦测角 θ**：以目标星为顶点，"目标→地心"与"目标→观测星"两条**有向**射线的夹角（0°–180°），要求 **θ ≤ 45°**。**不得对点积取绝对值**（150° 不能当 30°）。
- **连续观测时间**：上述全部条件须**连续满足至少 60 s**，不能只检查个别时刻。

## 四、机动约束

- 每次有效观测最多允许 **2 次瞬时脉冲机动**（0/1/2 次均可，不强制恰好两次）；
- 单次脉冲 ‖Δv_k‖ ≤ 0.03 km/s（30 m/s）；
- 同一观测星相邻两次机动间隔 ≥ 3600 s；
- 每颗观测星累计 Δv 预算 ≤ 0.3 km/s；
- 速度增量按三维矢量模长求和。

## 五、动力学模型要求

- 地球中心引力二体模型，μ = 398600.4418 km³/s²；不考虑 J2、日月三体、光压等摄动；
- 太阳仅提供光照几何（位置矢量），不产生加速度；
- 建议无机动段用解析开普勒传播，另用高精度数值积分独立验证；
- 脉冲机动满足位置连续、速度瞬时跳变；
- 建议检查轨迹不进入地球内部（R_E = 6378.137 km），此项作为物理安全检查单独记录。

## 六、数据文件

`数据.xlsx` 的 Sheet1：第 4 行 r1、第 5 行 r2（初始状态空）、第 6 行 b1、第 7–35 行 b2–b30（B–G 列依次为 x, y, z, vx, vy, vz）；第 38–44 行为观测与机动约束参数。使用时须重新读取并检验，不得依赖历史提取值。
