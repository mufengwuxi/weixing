# docs：建模与分析文档

文档按问题分目录，文件名统一写成 `v<版本号>_<主题>_<作者>.md`。版本号在同一问内递增，不同作者的平行版本可以用同一个版本号。出新版本时另存为新文件，不覆盖旧版，旧版是论文"模型改进"部分的素材。

| 目录 | 内容 |
|---|---|
| `00_题目/` | 题目全文、初步建模（三问递进框架）、约束核对 |
| `q1/` | 第一问：zzx 总结（v1）、复核意见（v1 复核）、Claude 独立求解（v2） |
| `q2/` | 第二问：zzx 进展（v1）、Claude 版（v2） |
| `q3/` | 第三问：Claude 双星分工（v1、v2） |
| `模型/` | 三问统一的模型抽象（论文第 2 节底稿） |

可以直接放进论文的成稿放在 `paper/sections/`，这里只放过程性的建模文档。
